# مخططات حالات الاستخدام

هذا المجلد يحتوي على مخططات PlantUML العربية المستخرجة من الكود الفعلي.

النطاق المستخدم هنا هو الأدوار المصادَق عليها فقط:

- `مستخدم مصادق`: جميع المزايا المتاحة بعد تسجيل الدخول.
- `مدير`: كل ما لدى المستخدم المصادق، إضافة إلى وظائف الإدارة.

الملفات:

- `overall-use-case.puml`: صورة عامة عالية المستوى للنظام.
- `roles/authenticated-user-use-case.puml`: حالات استخدام المستخدم المصادق.
- `roles/admin-use-case.puml`: حالات استخدام المدير.
- `modules/assistant-use-case.puml`: وحدة المساعد والتحليل.
- `modules/codeforces-solve-use-case.puml`: وحدة حل Codeforces.
- `modules/problems-use-case.puml`: وحدة بنك المسائل.
- `modules/courses-use-case.puml`: وحدة المسارات التعليمية.
- `modules/patterns-use-case.puml`: وحدة مكتبة الأنماط.
- `modules/submissions-use-case.puml`: وحدة الإرسالات.
- `modules/admin-use-case.puml`: وحدة الإدارة.
- `ai-use-case.puml`: حالات استخدام الذكاء الاصطناعي، مع الحد اليومي وسجل الاستخدام.

ملاحظات:

- تم استبعاد حالات الاستخدام الخاصة بالزائر مثل تسجيل الدخول والتسجيل من المخططات لأنك طلبت الاعتماد على الأدوار المصادَق عليها فقط.
- أي سلوك موسوم داخل هذا العمل على أنه `INFERRED` أو `UNKNOWN` يجب التعامل معه كإشارة توثيقية لا كوظيفة مؤكدة إذا لم يظهر صراحة في الكود.
