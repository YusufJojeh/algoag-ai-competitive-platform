# LinkedIn Post - Arabic

أنهيت العمل على ALGOAG، منصة تدريب برمجي تنافسي مبنية بـ Laravel 12 و React/Inertia مع واجهة Shadcn-style.

الفكرة ليست مجرد صفحة مسائل. المنصة تجمع تجربة كاملة:

- بنك مسائل مع Topics/Tags.
- إرسال حلول Python و C++.
- اختبارات مخفية داخل الـ judge.
- Mini Arena بأسلوب Codeforces للمسابقات timed/practice.
- standings.
- مسائل contest-only تبقى مخفية حتى تنتهي المسابقة.
- نشر تلقائي للمسائل بعد نهاية المسابقة مع حساب difficulty من أداء المشاركين.
- لوحة Admin لإدارة المستخدمين، المواضيع، المسارات، الدروس، المسائل، المسابقات والإعدادات.
- AI Assistant و Codeforces solver يدعمان Python/C++.

تعاملت مع المشروع كمنتج فعلي: backend validation، authorization، queue/scheduler، visibility rules، tests، وتوثيق تقني وتسويقي واضح.

ملاحظة هندسية مهمة: الـ local judge مناسب للديمو والتطوير المحلي، لكن تشغيل كود غير موثوق في الإنتاج يحتاج sandbox حقيقي مثل Docker/gVisor/Firejail.

الخطوة التالية: تسجيل demo قصير وتجهيز screenshots للـ portfolio.

لو مهتم بمراجعة المشروع أو إعطاء feedback تقني، يسعدني رأيك.
