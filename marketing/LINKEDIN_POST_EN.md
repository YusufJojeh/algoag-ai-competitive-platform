# LinkedIn Post - English

I finished ALGOAG, a competitive programming learning platform built with Laravel 12, React/Inertia, and Shadcn-style UI components.

It is more than a problem list. The platform includes:

- Topic-driven problem practice.
- Python and C++ submissions.
- Hidden judge test cases.
- A Mini Codeforces-style Arena for timed and practice contests.
- Standings.
- Contest-only private problems that stay hidden until the contest ends.
- Automatic post-contest publishing with computed difficulty based on participant performance.
- Admin management for users, topics, courses, lessons, problems, contests, and settings.
- AI assistant and Codeforces solver flows for Python/C++.

I treated this as a real product pass: backend validation, authorization, queue/scheduler workflows, visibility rules, tests, and release-ready documentation.

Important engineering note: the local judge is suitable for local demos and development. Production execution of untrusted code requires a real sandbox such as Docker, gVisor, or Firejail.
