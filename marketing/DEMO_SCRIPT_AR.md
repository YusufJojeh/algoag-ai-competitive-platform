# ALGOAG Demo Script - Arabic

المدة المستهدفة: 90 إلى 120 ثانية.

## Script

نبدأ من صفحة الهبوط. ALGOAG منصة تدريب برمجي تنافسي تجمع بنك مسائل، مسابقات Arena، إرسال حلول Python و C++، ومساعد AI في تجربة واحدة.

أسجل الدخول كمستخدم تجريبي، ثم أفتح صفحة Problems. هنا تظهر المسائل العامة مع الصعوبة والمواضيع المرتبطة بها. أختار مسألة، أقرأ الوصف، ثم أرسل حلا بلغة Python أو C++.

بعد الإرسال، ينتقل النظام إلى صفحة النتيجة. في وضع الديمو المحلي يمكن تشغيل judge الحقيقي عند تفعيل `JUDGE_USE_REAL=true` وتوفر Python و g++، أو استخدام stub الآمن افتراضيا. الاختبارات المخفية لا تظهر للمستخدم.

الآن ننتقل إلى Arena. قبل بداية المسابقة تظهر حالة Not started وعد تنازلي مبني على توقيت التطبيق. عند بدء المسابقة تتحول الحالة إلى Running ويستطيع المشاركون الذين انضموا إرسال الحلول. بعد ذلك نفتح Standings ونرى ترتيب المشاركين بأسلوب ICPC.

أنتقل الآن إلى لوحة Admin. من هنا يمكن إدارة المستخدمين، المواضيع، المسارات التعليمية والدروس، المسائل والتاغات، والمسابقات. في المسابقة يمكن للأدمن إضافة مسائل contest-only تبقى مخفية عن صفحة Problems حتى تنتهي المسابقة.

بعد انتهاء المسابقة، يشغل الـ scheduler أو الأمر اليدوي `php artisan arena:publish-ended-problems`. يتم نشر المسائل الخاصة تلقائيا، وتحسب الصعوبة من أداء المشاركين: عدد المشاركين، نسبة الحل، ووقت أول accepted.

أخيرا أعرض AI Assistant و Codeforces solver. يمكن للمستخدم طلب تحليل أو حل مسألة بأسلوب Python أو C++.

الخلاصة: ALGOAG ليس مجرد واجهة، بل نظام متكامل فيه Laravel backend، React/Inertia frontend، queue، scheduler، صلاحيات، اختبارات، وتوثيق جاهز للديمو.
